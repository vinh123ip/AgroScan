## Ba quy tắc không được quên

1. Yêu cầu "xem / phân tích / đánh giá / đề xuất / giải thích" nghĩa là **chỉ đọc, không sửa tệp**.
2. Nhiệm vụ lớn: trình bày kế hoạch rồi **chờ "OK"** mới viết code (`RULES.md` mục 7).
3. Không tự quyết: schema DB, công nghệ chính, dependency, logic nghiệp vụ. Xem mục "Chờ quyết định" trong `DECISIONS.md`.
