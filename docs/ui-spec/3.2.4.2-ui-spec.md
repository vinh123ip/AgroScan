### 2.2 Domain & API Field Mapping

| Domain Field (`Product` / `DefectCriterion`) | Type | UI Widget in `CatalogPage` | Validation Rule (`catalog_validation.py`) |
|---|---|---|---|
| `Product.code` | `str` | `code_field` (`QLineEdit`) | `^[A-Z][A-Z0-9_]{1,19}$`, unique across catalog, immutable after creation |
| `Product.name` | `str` | `name_field` (`QLineEdit`) | Required, 1–60 chars |
| `Product.category` | `str` | `category_field` (editable `QComboBox`) + `category_filter` | Required non-empty string; populates Goods Category filter |
| `Product.model_file` | `str` | `model_field` (`QLineEdit`) | Filename without path separators, suffix in `(.onnx, .pt, .engine)` |
| `Product.detect_classes` | `list[str]` | `classes_field` (`QLineEdit`, comma-separated) | ≥ 2 unique lowercase identifiers (`^[a-z][a-z0-9_]{0,31}$`); index `0` = healthy class |
| `Product.min_objects` | `int` | `min_objects_spin` (`QSpinBox`) | `1..500`; below threshold triggers `AiRecommendation.NEEDS_REVIEW` |
| `Product.min_confidence` | `float` | `min_conf_spin` (`QSpinBox`, `0..100 %`) | `0.0..1.0`; below threshold triggers `NEEDS_REVIEW` and deep-analysis hint |
| `DefectCriterion.defect_class` | `str` | Column 0 `QComboBox` in `criteria_table` | Must belong to `detect_classes[1:]` (healthy class excluded), unique per product |
| `DefectCriterion.max_ratio` | `float` | Column 1 `QDoubleSpinBox` (`0.0..100.0 %`) | `0.0..1.0`; disabled when `is_critical=True` |
| `DefectCriterion.is_critical` | `bool` | Column 2 `QCheckBox("Fail immediately")` | Any count > 0 proposes `AiRecommendation.FAIL` immediately |

### 3.2 Field Mapping

| Field / Input | Source / Parser | Target UI Widget | Validation & Error Handling |
|---|---|---|---|
| QR String (`AGS:<ORDER>-<BOX>/<TOTAL>`) | `BoxCode.parse` + `MockRepository.resolve_box` | `scan_field` (`#ScanField`) on `returnPressed` | Regex `^AGS:(?P<order>[A-Z0-9]+)-(?P<box>\d{1,4})/(?P<total>\d{1,4})$`, checks `1 <= box <= total` and `order.total_boxes == total`; errors shown in `#InlineErrorLabel` |
| Manual Order & Box # | `order_combo` + `box_spin` | `btn_lookup` builds canonical `BoxCode.text` | Spinbox range dynamically bound to `1..order.total_boxes` |
| Order Metadata | `Order`, `Product` | `info_grid` (`KeyValueGrid(columns=3)`) | Displays Order Code, Box `k of N`, Product Name, Supplier, Expected Quantity, YOLO Model file |
| Re-inspection History | `repo.records_for_box(box_code)` | `reinspect_label` (`#WarningNote`) | Warns when prior sessions exist; preserves history and opens a new session (`D-021`) |
| Continuous Next-Box Scan | `LiveInspectionPage.next_scan_field`, `AssessmentResultPage.next_scan_field` | `MainWindow._on_next_box` | Auto-submits current session to `PENDING_REVIEW` and opens the newly scanned box (`D-020`) |

### 4.2 API Contract & Field Mapping (`docs/api/vlm_analysis.schema.json` → `VlmResultPanel`)

Endpoint: `POST /api/v1/vlm/analyze` (LAN HTTP REST on the server, `D-017`).
Validator: `parse_vlm_response(payload)` in `src/agroscan/models/vlm_models.py`.

| JSON Path (`vlm_analysis.schema.json`) | JSON Type / Constraints | Python Model (`vlm_models.py`) | UI Widget in `VlmResultPanel` | UI Behavior |
|---|---|---|---|---|
| `$.schema_version` | `"1.0"` (`const`) | `VlmAnalysis.schema_version` | Validated in `parse_vlm_response` | Rejects mismatched versions with `VlmSchemaError` → `INVALID_RESPONSE` |
| `$.request_id` | `string` | `VlmAnalysis.request_id` | `meta_label` (`#HintLabel`) | Displayed in metadata subtitle and error details |
| `$.status` | `"ok" \| "partial" \| "error"` | `VlmAnalysis.status` (`VlmStatus`) | `status_badge` (`StatusBadge`) | Maps to `good` (`OK`), `warning` (`PARTIAL`), `critical` (`ERROR`) |
| `$.model` | `string` | `VlmAnalysis.model` | `meta_label` | Shown in header metadata |
| `$.latency_ms` | `integer >= 0` | `VlmAnalysis.latency_ms` | `meta_label` | Formatted in seconds (`1.4 s`) |
| `$.analyzed_at` | `string (date-time)` | `VlmAnalysis.analyzed_at` (`datetime`) | `meta_label` | Formatted as `HH:MM:SS` |
| `$.warnings[]` | `array<string>` | `VlmAnalysis.warnings` | `warnings_label` (`#WarningNote`) | Visible when non-empty (e.g., partial OCR warning) |
| `$.defects[].defect_class` | `string (minLength 1)` | `VlmDefect.defect_class` | `defect_grid` col 0 (`#VlmValue`) | Capitalized defect name; tooltip shows `description` |
| `$.defects[].count` | `integer >= 0` | `VlmDefect.count` | `defect_grid` col 1 (`#VlmValue`) | Count reported by VLM |
| `$.defects[].severity` | `"minor" \| "major" \| "critical"` | `VlmDefect.severity` (`DefectSeverity`) | `defect_grid` col 2 (`#VlmValue` / `#VlmCritical`) | `critical` rendered in bold red (`▲ Critical`) |
| `$.defects[].confidence` | `number 0..1` | `VlmDefect.confidence` | `defect_grid` col 3 (`#VlmValue`) | Formatted as percentage (`84%`) |
| `$.defects[].description` | `string` | `VlmDefect.description` | `defect_grid` row tooltip | Hover tooltip on defect class cell |
| `$.defects[].region` | `array[4] of 0..1 \| null` | `VlmDefect.region` | Validated & preserved on model | Normalized `[x, y, w, h]` for future overlay rendering |
| `$.ocr.readable` | `boolean` | `VlmOcrResult.readable` | `ocr_note` (`#WarningNote`) | If `false` or `ocr is null`, shows warning banner instead of field table |
| `$.ocr.fields[].key` | `string` | `OcrField.key` / `OcrField.label` | `ocr_grid` col 0 (`#FormLabel`) | Mapped via `OCR_FIELD_LABELS` (`box_code`, `supplier`, `packed_date`, `lot_number`, `origin`, `net_weight`) |
| `$.ocr.fields[].value` | `string` | `OcrField.value` | `ocr_grid` col 1 (`#VlmValue`) + `#VlmMismatch` | Compared against order values (`box_code`, `supplier`); mismatches add a `≠ Differs from order` badge |
| `$.ocr.fields[].confidence` | `number 0..1` | `OcrField.confidence` | `ocr_grid` col 2 (`#HintLabel`) | Formatted as percentage |
| `$.ocr.raw_text` | `string` | `VlmOcrResult.raw_text` | Stored in `VlmOcrResult` | Preserved for audit/export |
| `$.uncertainty.level` | `"low" \| "medium" \| "high"` | `VlmUncertainty.level` (`UncertaintyLevel`) | `uncertainty_badge` (`StatusBadge`) | Maps to `good` (`low`), `warning` (`medium`), `critical` (`high`) |
| `$.uncertainty.score` | `number 0..1` | `VlmUncertainty.score` | `uncertainty_badge` | Displayed alongside level (`MEDIUM · 0.42`) |
| `$.uncertainty.reasons[]` | `array<string>` | `VlmUncertainty.reasons` | `uncertainty_reasons` (`#VlmValue`) | Bullet list explaining why uncertainty is elevated |
| `$.observations[]` | `array<string>` | `VlmAnalysis.observations` | `observations_label` (`#VlmValue`) | Bullet list of visual observations |
| `$.assessment` | `string` | `VlmAnalysis.assessment` | `assessment_label` (`#VlmValue`) | AI interpretation separated from observations |
| `$.suggestion` | `string` | `VlmAnalysis.suggestion` | `suggestion_label` (`#VlmValue`) | Recommended next action for the operator |
| `$.error.code` | `"TIMEOUT" \| "SERVICE_UNAVAILABLE" \| "INVALID_RESPONSE" \| "IMAGE_UNUSABLE" \| "MODEL_ERROR"` | `VlmError.code` (`VlmErrorCode`) | `error_title` (`#VlmErrorTitle`), `error_advice` | Maps to code-specific title and operator recovery guidance |
| `$.error.message` | `string` | `VlmError.message` | `error_message` (`#VlmErrorText`) | Selectable error detail with `[CODE]` tag |
| `$.error.retryable` | `boolean` | `VlmError.retryable` | `btn_retry` (`#SecondaryButton`) | Shows `Retry` button when `true`; hides it for non-retryable `IMAGE_UNUSABLE` |
